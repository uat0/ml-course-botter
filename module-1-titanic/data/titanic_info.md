# Датасет Titanic

**Источник:** [Kaggle — Titanic: Machine Learning from Disaster](https://www.kaggle.com/c/titanic)

| Файл | Строк | Описание |
|---|---|---|
| `train.csv` | 891 | обучающая выборка с целевой переменной `Survived` |
| `test.csv` | 418 | тестовая выборка без целевой переменной |
| `submission.csv` | 418 | предсказания лучшей модели в формате Kaggle |

## Признаки
| Признак | Описание |
|---|---|
| `PassengerId` | ID пассажира |
| `Survived` | 0 — не выжил, 1 — выжил (целевая) |
| `Pclass` | класс билета: 1, 2, 3 |
| `Name` | имя с титулом |
| `Sex` | пол |
| `Age` | возраст (≈ 20% пропусков) |
| `SibSp` | братья/сёстры/супруги на борту |
| `Parch` | родители/дети на борту |
| `Ticket` | номер билета |
| `Fare` | стоимость билета |
| `Cabin` | каюта (≈ 77% пропусков) |
| `Embarked` | порт посадки: C — Шербур, Q — Квинстаун, S — Саутгемптон |

Баланс классов: 549 погибших (61.6%) / 342 выживших (38.4%).
